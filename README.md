# 🍲 Recettes des Mim's

App web mobile-first pour planifier les repas de la semaine (3 personnes, 4 parts par plat) à partir d'une base de recettes et d'un cadre de règles d'équilibre.

## Utilisation
Ouvrir `index.html` dans un navigateur. Trois onglets :
- **Semaine** — génère automatiquement le menu (Lun→Dim) selon les règles, régénère un jour, marque un plat « fait ».
- **Recettes** — parcourir/chercher les 44 recettes.
- **Historique** — repas cochés + notes ★ ; alimente l'anti-répétition (une recette vue sur 3 semaines n'est pas re-proposée).

## Déploiement
Aucun build. Pousser sur GitHub, activer **GitHub Pages** (branche `main`, dossier racine) → accessible depuis le téléphone.
